## 🛡️ Source Transparency & Copyright Compliance

1. **No Pirated Materials**: We strictly reject unauthorized digital PDFs, leaked papers, or scans. Standard books link exclusively to authorized publisher stores (Arihant, Disha, Kiran, Pathfinder, McGraw Hill, Pearson). NCERT links resolve directly to official open repositories at `ncert.nic.in`.
2. **Transparent Question Provenance**:
   - **`VERIFIED PYQ`**: Authenticated past examination questions with verified official keys.
   - **`ORIGINAL`**: High-yield model practice questions created from current syllabus standards.
   - **`PYQ-STYLE`**: Modeled on previous pattern variations.
   *We never misrepresent synthetic questions as actual previous year papers.*
3. **Statutory Non-Affiliation**: This educational platform is an independent study aid not affiliated with NTA, CBSE, KVS, SSC, or any governmental agency.

## 🛠️ Local Development & Build

### Prerequisites
- Node.js 18+ or 20+
- npm (or npm.cmd on Windows)

### Commands
```bash
# Clone the repository
git clone https://github.com/raghavendra-exp/general-science-teaching-master.git
cd general-science-teaching-master

# Install dependencies
npm install

# Run data integrity validation
npm run validate:data

# Launch development server
npm run dev

# Compile TypeScript and build for production
npm run build

# Preview production build locally
npm run preview
```
